# Zodiac Killer Locations — Interactive Map

A full-screen interactive map of locations from Robert Graysmith's
*Zodiac* (1986), built with [MapLibre GL JS](https://maplibre.org/).

## Features

- Full-screen map with dark basemap
- Optional globe projection
- Category toggles (crime scenes, victims, police, letters, suspects, landmarks, cities)
- "Show labels" overlay
- Click any marker to open a detail panel with **every property** in the GeoJSON record
- Responsive layout
